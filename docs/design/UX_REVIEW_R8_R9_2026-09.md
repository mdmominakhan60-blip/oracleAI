# UX-ревью реализаций R-8 / R-9 (BUS-509 / BUS-510) — 2026-09-08

Вердикт UX/UI Designer по соответствию реализаций спекам находок гейта P2-002.

Ревью сделано на незакоммиченной ветке ~01:00Z, затем Frontend закоммитил
финальные версии: `bb529b3` (BUS-510) и `d27c09c` (BUS-509) с доработками
после моего ревью. Финальные смоуки прогнаны мной на коммитах.

## Вердикт: соответствие подтверждено, расхождений со спекой нет

### BUS-509 (R-8, Chat viewport) — PASS

Прогон `scripts/qa_bus509_smoke.mjs` на коммите `d27c09c`: **33/33 PASS**
(на ревью-точке было 26/33 — 7 FAIL «консоль чиста» были mock-шумом и
устранены Frontend до коммита).

Пункты спеки, подтверждённые прогоном и код-ревью:

- **R-8.1 nav-hidden**: `.app-nav` и `.app-header` скрыты в чате
  (`display:none` — высота реально возвращается ленте, не перекрывается).
  Путь назад сохранён дважды: back-кнопка в `.chat-head` + BackButton
  Telegram (`syncBackButton`, 05-app.js). После выхода навигация
  возвращается (проверено смоуком).
- **R-8.2 heads-hidden**: порог дельты 36px отсекает микродрожание и
  iOS-резинку; возврат при `y <= 0`. `max-height:0 + min-height:0` —
  место отдаётся ленте; числовая база `max-height:120px` в `nav-hidden`
  нужна, чтобы transition вообще анимировался (none→0 не анимируется).
  Frontend нашёл и закрыл осцилляцию у нижнего края (кламп scrollTop
  читался как «вверх» — гасится 400ms-окном подавления) — принято,
  дефект был реальный, но на границе спеки.
  Reduced-motion-гард на transition (WCAG 2.3.3, гейт P2-002 §7) — PASS.
- **R-8.3 intro-collapse**: при stable-высоте < 480px карточка агента —
  одна строка kicker (persona/next скрыты), при возврате к 667px полный
  вид восстанавливается.
- **R-8.4 stable-высота**: `viewportStableHeight` + `isStateStable` (не
  `viewportHeight`) — ровно по документации Telegram для pinned-композера.
  Событие без `isStateStable` значение НЕ меняет (проверено). Композер
  остаётся в layout при клавиатуре 320px.
- **Деталь выше спеки (одобряю)**: `renderFrame` сохраняет классы
  `nav-hidden`/`heads-hidden`/`chat-live` при перерендере — без этого
  смена языка внутри чата роняла бы viewport-состояние.

### BUS-510 (R-9, Onboarding intro) — PASS

Прогон `scripts/qa_bus510_smoke.mjs` на коммите `bb529b3`: **56/56 PASS**
на трёх вьюпортах (android-375, iphone-390, desktop-1024).

- Одна ось колонки: title/dots/start/skip — центрирование задаётся на общем
  wrapper `#intro` (`align-items:center`), двойное центрирование устранено.
  Отклонение оси ≤1px на всех слайдах и всех вьюпортах.
- Кнопка «Дальше/Начать» в границах вьюпорта (раньше уезжала вправо за экран).
- `min-height: 2.6em` у `.intro-title` — dots не прыгают по вертикали
  между слайдами (maxDev=0px).
- CTA-слайд натальной карты до-добавляется живьём после `/api/me`
  (`introMaybeAddChartSlide`) — сохраняет язык-первый-шаг (BUS-397),
  активный dot и подпись «Начать» пересчитываются. PASS.
- Reduced-motion: ось сохранена, оверлей рендерится.
- Контраст «Пропустить»: #948cb2 на градиенте #0d0b1e/#08070f —
  6.1–6.4:1, AA для мелкого текста пройден.

# R05 — Система фона и motion OracleAI
**Задача:** BUS-733 (волна A эпика BUS-721 «новый дизайн»). **Вход:** план BUS-721 §7 (фон как система §7.1, девушка §7.2, анимации §7.3), §16 E18/E23; R03 дизайн-система (`REDESIGN_R03_DESIGN_SYSTEM.md`, коммит `7f7c79a`, §6 motion, §2 токены); R04 identity (`REDESIGN_R04_AGENT_IDENTITY.md`, rev 3, ART-05/06/07, бюджеты); R02 IA (`REDESIGN_R02_IA_NAVIGATION.md`, `7f7cd3b`); R01 baseline (`8fbb477`).
**Статус:** проект к независимой приёмке Frontend Engineer (perf-бюджет анимаций) + проверка E23 (keyboard/screen reader/reduced motion).
**Сверено с кодом:** `miniapp/css/01-sky-shell.css` (starfield, galaxies, lilith-sil), `04-atmosphere.css` (meteor, twinkle), `07-home-bg.css` (nebula), `16-visual-qa.css`, `miniapp/index.html:17-46` (sky-контейнер), `05-app.js:515-528` (параллакс), `miniapp/img/` (bg-cosmos.jpg 872×1300 41KB, lilith-sil.png 387×800 307KB).

## 0. Роль этого документа

Нормативная спецификация фоновой системы и движения для R06-макетов и реализации. Фон — **управляемая система слоёв с состояниями**, не декорация: у каждого слоя есть назначение, состояние экрана управляет его интенсивностью, бюджет производительности ограничивает всё. Девушка (агент-силуэт/портрет) — часть системы размещения, не перекрывает текст и не перехватывает клики (план §7.2).

**Что не менять:** живой космический фон не заменяется однотонной заливкой (§1.2 плана); предметная логика не затрагивается.

## 1. Архитектура фона: слои и контейнер (план §7.1)

### 1.1. Слой-стек (снизу вверх), фиксированный порядок

| # | Слой | Технология | Назначение | Источник |
|---|------|-----------|------------|----------|
| L0 | Базовый градиент ночи | CSS gradient | Глубина, `--color-bg #0B0D18` | R03 §2.1 |
| L1 | Атмосферное изображение | JPEG/WebP `<img>`/background | Материя неба, туманности | ART-06 |
| L2 | Звёзды (статичные) | CSS radial-gradient tiles | Плотность, мерцание — точечно | перенос из starfield::before/after |
| L3 | Созвездия | инлайн SVG | Нарратив, узнаваемость «космос = астрология» | текущие `.constellations` |
| L4 | Динамика (галактики, метеоры) | CSS-элементы, ограниченный пул | Живость — **единственные** движущиеся слои | текущие `.galaxy/.meteor` |
| L5 | Агент (девушка) | `<img>` ART-05 | Персонаж, эмоциональный якорь | R04 §5 |

Правила: слой L1 — максимум **один** графический файл на состояние; слои не дублируют друг друга (если L1 содержит туманность — CSS-nebula в этом состоянии не рисуется); `z-index` фона ≤ −1; весь стек — `position: fixed`, `pointer-events: none` (уже так — сохранить), `aria-hidden="true"` на контейнере.

### 1.2. Контейнер и растяжение (ловушка текущей базы)

Сейчас `bg-cosmos.jpg` — 872×1300, `background-size: cover` на десктопе 2560×1440 растягивает в ~3× (мыло). Требования:

- Поставляются **два мастер-кадра** ART-06: desktop 2560×1440 (≥2048 ширина) и mobile 1080×1920; выбор — media-query `min-width: 768px`, не `srcset` (фон в CSS).
- Переключение состояний меняет `opacity`/`visibility` слоёв, **не** размер; кросс-фейд 300–480 мс (`--motion-slow`).
- Проверка приёмки: 1080×1920 и 2560×1440 без апскейла мастера; «тихая зона» под текст — левая/центральная нижняя треть L1 свободна от ярких объектов (приёмка ART-06 «без швов, тихая область под чтением»).

### 1.3. Состояния фона (план: welcome/chat/Tarot × mobile/ПК)

| Состояние | Экраны (R02) | L1 кадр | L4 динамика | L5 агент | Интенсивность |
|---|---|---|---|---|---|
| `bg:welcome` | S01–S03 (Сегодня, первый вход) | ART-06 welcome (более выразительный) | метеоры вкл, галактики вкл | силуэт/портрет крупнее (desktop ART-05, mobile 9:16-кадр) | 100% |
| `bg:chat` | Чат S04 | ART-06 chat (приглушённый, та же сцена) | метеоры выкл, галактики на 60% opacity | нет/мини-аватар в шапке | 70% |
| `bg:tarot` | S13 Таро | ART-06 chat (тот же) | всё выкл, кроме перевертыша карт | нет | 60% |
| `bg:work` | Формы, библиотека, профиль | только L0+L2 | выкл | нет | 50% |

Механика: атрибут `data-bg` на `#app-root`, состояния объявляются в одном месте (переключатель вью уже в `05-app.js`), компоненты не выставляют фон сами. Внутри состояния допускается не более **двух** одновременно анимирующихся слоёв (см. perf-бюджет §4).

### 1.4. Параллакс (существующий, сохранить с ограничением)

Текущий параллакс `05-app.js:522-527` (translateY 0.08×scrollTop, только вне чата) — оставить как есть; в состоянии `bg:chat` параллакс выключен (правило уже в комментарии кода — фиксируем в спеке). Transform только на контейнере, не на слоях по отдельности.

## 2. Девушка/агент: размещение (план §7.2)

### 2.1. Правила размещения

1. **Не перекрывает текст:** контентные колонки поверх слоя L5 получают фон поверхности (`--color-surface` с opacity ≥ .92) или L5 смещается в зону без контента. Проверка: worst-case — самое длинное имя агента + перенос строки поверх силуэта на 360px ширине.
2. **Не перехватывает клики:** `pointer-events: none` на L5 и всём sky-контейнере (уже выполнено — регресс-тест в §6).
3. **Привязка к агенту:** в Чате с выбранным агентом L5 не рисуется (портрет уже в шапке чата 56–80px по ART-01…04); L5 — только welcome/Сегодня (нейтральный образ-хозяйка = Лилит/oracle, либо безагентный силуэт по решению R06).
4. **Масштаб:** desktop — ART-05 силуэт высотой 60–80vh у правого края; mobile — 9:16-кроп верхней третью головы, нижние 2/3 уходят под градиент в палитру агента (канон R04 §6).
5. **Анимация L5:** один цикл дыхания 16 с (существующий `lilBreathe`, scale ≤ 1.012, opacity .5–.62) — только в `bg:welcome`; в остальных состояниях статичен.

### 2.2. Доступность образа

`alt=""` + `aria-hidden="true"` (уже так) — образ декоративный, имя агента озвучивается текстом интерфейса, не картинкой. Контраст текста поверх L5 проверяется по L0–L1, не по самой фигуре: под зоной чтения L5 затемняется локальным градиентом (per-агентный hex запрещён — только производные от семантических токенов, R03 §2.1).

## 3. Motion-спецификация (план §7.3; базис R03 §6)

### 3.1. Реестр движений фона (полный)

R03 §6.1 задаёт темп; здесь — фоновые события в тех же токенах:

| Событие | Слой | Параметры | Состояния | Reduced motion |
|---|---|---|---|---|
| Дрейф звёзд | L2 | `starDrift` 90–140 с, linear | welcome, chat | стоп, статика |
| Пульс галактики | L4 | `gPulse` 14 с, opacity-только | welcome, chat@60% | стоп, opacity фикс .3 |
| Метеор | L4 | `meteorFall` 7–13 с, пул 4, пауза между сериями ≥ 20 с | welcome только | скрыт (`display:none`, уже так) |
| Дыхание агента | L5 | `lilBreathe` 16 с, scale ≤1.012 | welcome только | стоп, статичный кадр |
| Кросс-фейд состояния | весь стек | 300–480 мс `--motion-slow`, opacity | все переключения | мгновенная смена |
| Переворот Таро | карты | 450–600 мс на карту (R03 §6.1) | bg:tarot | показ без 3D (R03) |
| Появление sheet/шага | UI | 180–240 мс (R03 §6.1) | все | без перемещения (R03) |

Запреты (наследуются из R03 §6.2 + план §7.3): не анимировать `filter: blur`, `background-position` на больших областях, layout-свойства; no ВЕБ-звук; виджет-фаз луны и карточки агентов — по R03, здесь не дублируются.

### 3.2. Пауза фона — настройка пользователя (план E18)

**Требование W3C Pause-Stop-Hide (2.2.2):** автодвижение > 5 с должно иметь механизм паузы. Reduced motion — это системная настройка, не замена кнопки (R03 §6.2 уже фиксирует; здесь — реализация).

- Настройка **«Анимация фона»** в Профиле (S-экран Профиля, R02): toggle, default = «вкл».
- Хранение: localStorage `oracle.bgAnimation` (наследует паттерн локальных настроек миниаппа; синхронизация с аккаунтом — вне скоупа A).
- Действие: класс `bg-paused` на `#app-root` → все `animation` слоёв L2–L5 = `none`, статичный кадр (первый кадр каждого цикла), метеоры скрыты. L0/L1/L3 остаются (композиция не «умирает»).
- Формулировка настройки: «Анимация фона. Можно выключить, если движение отвлекает или тратит батарею» + подпись, что чтение/функции не зависят от анимации.
- Пауза также автоматом: `visibilitychange` → `animation-play-state: paused` (текущий R03-запрос — зафиксировать реализацией), вкладка Telegram WebApp в фоне не тикает.

### 3.3. Reduced motion (план E23; R03 §6.3)

Единый блок в `00-tokens.css` (R03 §6.3), покрывающий **все** слои:

```css
@media (prefers-reduced-motion: reduce) {
  .starfield::before, .starfield::after, .galaxy, .nebula,
  .lilith-sil, .meteor, .twinkle, .constellations { animation: none !important; }
  .meteor { display: none; }
  /* статические композиции сохраняются; кросс-фейд состояний — мгновенный */
  #app-root, .sky-layer { transition: none !important; }
}
```

**Гэп текущей базы (исправить при реализации):** сейчас блоки reduced-motion размазаны по модулям (04, 07 — `!important` нет; `starDrift`, `gPulse`, `lilBreathe`, `nebulaDrift` не покрыты). Спека требует один authoritative-блок; локальные правила модулей удалить.

## 4. Perf-бюджет (план §16.1; проверка Frontend Engineer)

### 4.1. Бюджеты

| Метрика | Порог | Как мерить |
|---|---|---|
| Одновременных CSS-анимаций | ≤ 2 слоя на состояние | DevTools Rendering → Animation |
| CSS-анимации — только `transform`/`opacity` | 100% слоёв фона | код-ревью: ни одного `filter`/`background-position`/layout в @keyframes фона |
| Вес декора первого экрана (mobile) | ≤ 250 KB суммарно | сетевой лог при первом входе |
| Вес декора (desktop) | ≤ 450 KB | то же |
| Фоновое изображение L1 | mobile ≤ 120 KB WebP (или JPEG ≤ 160 KB), desktop ≤ 200 KB WebP | сжатие при поставке ART-06 |
| Силуэт L5 (ART-05) | ≤ 80 KB WebP, alpha | ре-экспорт из ≥2000px мастера |
| Main-thread jank при скролле чата | нет дропов > 3 кадров подряд | профилировка на среднем Android (Moto G-класс) |
| FPS фоновых анимаций | ≥ 55 на desktop, ≥ 50 на мобильном | DevTools Performance 10-с замер |

### 4.2. Гэпы текущей базы (обязательные исправления)

1. **lilith-sil.png = 307 KB при 387×800** — превышает бюджет декора mobile в одиночку. Требование: альфа-силуэт из ART-05 (≥2000px мастер) → WebP ≤ 80 KB, ретина-пара (×1/×2), `loading="eager"` только на welcome.
2. **bg-cosmos.jpg 872×1300 (41KB)** — пригоден только как mobile-композиция L2-подложки, не как cover-фон desktop. Заменяется ART-06-кадрами (§1.2); старый файл остаётся фолбэком `no-image` (простой градиент, не растянутый апскейл).
3. **`filter: blur(60px)` на `.nebula`** — дорого на мобильных GPU: перенести размытие в саму текстуру ART-06 (размытие при генерации), CSS-blur удалить.
4. **mix-blend-mode: screen на `.galaxy`** — композитинг-стоимость на каждом кадре; заменить предумноженной прозрачностью (opacity-only анимация уже соответствует).
5. Дубли анимаций `15-ritual-redesign.css` (42 штуки, ~в 4 раза больше остальных модулей) — вне скоупа фона, но помечено для R06/дизайн-ревью: их не переносить в новые макеты без perf-сверки.

### 4.3. Прогрессивная загрузка

1. Первая отрисовка: L0 (градиент) + L2 (звёзды) — 0 KB, мгновенно.
2. L1 (фон ART-06) — `loading="eager"`, `fetchpriority="high"` (паттерн уже в index.html), mobile-кадр на mobile.
3. L3 SVG созвездия — инлайн (уже), вес ~2 KB — остаётся.
4. L5 агент — `loading="lazy"` кроме welcome; декод async.
5. Метеоры/галактики — активируются после `load` L1 (не конкурируют за первый кадр).

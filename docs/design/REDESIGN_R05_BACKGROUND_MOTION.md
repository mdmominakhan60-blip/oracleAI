## 0. Роль этого документа

Нормативная спецификация фоновой системы и движения для R06-макетов и реализации. Фон — **управляемая система слоёв с состояниями**, не декорация: у каждого слоя есть назначение, состояние экрана управляет его интенсивностью. Девушка — часть системы размещения: не перекрывает текст и не перехватывает клики (план §7.2).

**Что не менять:** живой космический фон не заменяется однотонной заливкой (§1.2 плана); предметная логика не затрагивается; новые изображения не создаются (борд BUS-963).

## 1. Архитектура фона: слои и контейнер (план §7.1)

### 1.1. Слой-стек (снизу вверх), фиксированный порядок

| # | Слой | Технология | Назначение | Источник (существующий) |
|---|------|-----------|------------|----------|
| L0 | Базовый градиент ночи | CSS gradient | Глубина, `--color-bg #0B0D18` | R03 §2.1 |
| L1 | Атмосферное изображение | JPEG `background` | Материя неба | `bg-cosmos.jpg` mobile / `bg-cosmos-2.jpg` ≥601px (пара уже в коде) |
| L2 | Звёзды (статичные) | CSS radial-gradient tiles | Плотность, мерцание — точечно | `starfield::before/after` |
| L3 | Созвездия | инлайн SVG | Нарратив «космос = астрология» | текущие `.constellations` |
| L4 | Динамика (галактики, метеоры) | CSS-элементы, ограниченный пул | Живость — **единственные** движущиеся слои | текущие `.galaxy/.meteor/.twinkle/.nebula` |
| L5 | Агент (девушка) | `<img>` PNG alpha | Персонаж, эмоциональный якорь | текущий `lilith-sil.png` |

Правила: слой L1 — максимум **один** файл на состояние (уже соблюдено парой космос/космос-2); слои не дублируют друг друга; `z-index` фона ≤ −1 (в 15-ritual-restack — 0 под `#app-root`, изоляция сохраняется); весь стек — `position: fixed`, `pointer-events: none` (уже так — сохранить), `aria-hidden="true"` на контейнере.

### 1.2. Контейнер и растяжение

Текущая пара файлов: mobile `bg-cosmos.jpg` 872×1300 (апскейл на 390×844@2x ≈ 1.3× — допустимо), desktop `bg-cosmos-2.jpg` 1300×1300 (апскейл на 2560×1440 ≈ 2× — виден, принято бордом для волны A, см. §7). Требования к реализации:

- Переключение состояний меняет `opacity`/`visibility` слоёв, **не** размер; кросс-фейд 300–480 мс (`--motion-slow`).
- Выбор кадра — media-query `min-width: 601px` (текущий порог кода — сохранить), не `srcset`.
- «Тихая зона» под текст: композиция 58% 30% (desktop) и 50% 18% (mobile) сохраняется — светлые объекты не садятся под колонку чтения; проверка при дизайн-ревью R06.

### 1.3. Состояния фона (welcome/chat/Tarot × mobile/ПК)

| Состояние | Экраны (R02) | L1 кадр | L4 динамика | L5 агент | Интенсивность |
|---|---|---|---|---|---|
| `bg:welcome` | S01–S03, первый вход | bg-cosmos (пара по ширине) | метеоры вкл, галактики вкл | lilith-sil крупнее (mobile 34%/150px-кадр уже в коде) | 100% |
| `bg:chat` | Чат S04–S07 | та же пара | метеоры выкл, галактики 60% opacity | нет (портрет в шапке чата) | 70% |
| `bg:tarot` | S13 Таро | та же пара | всё выкл, кроме переворота карт | нет | 60% |
| `bg:work` | Формы, библиотека, профиль | только L0+L2 | выкл | нет | 50% |

Механика: атрибут `data-bg` на `#app-root`, состояния объявляются в одном месте (переключатель вью уже в `05-app.js`), компоненты не выставляют фон сами. Интенсивность — через `opacity` контейнера/слоёв, не через новые файлы. Внутри состояния не более **двух** одновременно анимирующихся слоёв (§4).

### 1.4. Параллакс (существующий, сохранить с ограничением)

Текущий параллакс `05-app.js:522-527` (translateY 0.08×scrollTop, только вне чата) — оставить как есть; в состоянии `bg:chat` параллакс выключен (правило уже в комментарии кода — фиксируем в спеке). Transform только на контейнере, не на слоях по отдельности.

## 2. Девушка/агент: размещение (план §7.2)

### 2.1. Правила размещения

1. **Не перекрывает текст:** контентные колонки поверх L5 получают фон поверхности (`--color-surface`, opacity ≥ .92) или L5 смещается в зону без контента. Проверка: worst-case — самое длинное имя агента + перенос строки поверх силуэта на 360px ширине.
2. **Не перехватывает клики:** `pointer-events: none` на L5 и всём sky-контейнере (выполнено — регресс-тест в §6).
3. **Привязка к агенту:** в Чате с выбранным агентом L5 не рисуется (портрет в шапке чата по R04 ART-01…04 — существующие фото); L5 — только welcome/Сегодня (нейтральный образ-хозяйка = Лилит/oracle, либо безагентный силуэт — решение R06).
4. **Масштаб:** desktop — силуэт высотой 60–80vh у правого края (текущий `width:38%; max-width:220px` — нижняя граница диапазона, точное значение фиксирует макет R06); mobile — нижне-правое размещение, нижние 2/3 уходят под градиент.
5. **Анимация L5:** один цикл дыхания 16 с (существующий `lilBreathe`, scale ≤ 1.012, opacity .5–.62) — только в `bg:welcome`; в остальных состояниях статичен.

### 2.2. Доступность образа

`alt=""` + `aria-hidden="true"` (уже так) — образ декоративный, имя агента озвучивается текстом интерфейса. Контраст текста поверх L5 проверяется по L0–L1, не по фигуре: под зоной чтения L5 затемняется локальным градиентом от семантических токенов (per-агентный hex запрещён, R03 §2.1).

## 3. Motion-спецификация (план §7.3; применение R03 §6 к живому космосу)

### 3.1. Реестр движений фона (полный)

R03 §6.1 задаёт темп; здесь — фоновые события в тех же токенах, поверх существующих слоёв:

| Событие | Слой | Параметры | Состояния | Reduced motion |
|---|---|---|---|---|
| Дрейф звёзд | L2 | `starDrift` 90–140 с, linear | welcome, chat | стоп, статика |
| Пульс галактики | L4 | `gPulse` 14 с, opacity-только | welcome, chat@60% | стоп, opacity фикс .3 |
| Дрейф туманности | L4 | `nebulaDrift` 26–32 с, translate+scale | welcome, chat | стоп, статичная композиция |
| Метеор | L4 | `meteorFall` 7–13 с, пул 4, пауза между сериями ≥ 20 с | welcome только | скрыт (`display:none`, уже так) |
| Мерцание звёзд | L2 | `twinkle` 3.4 с, точечные | welcome, chat | стоп |
| Дыхание агента | L5 | `lilBreathe` 16 с, scale ≤1.012 | welcome только | стоп, статичный кадр |
| Кросс-фейд состояния | весь стек | 300–480 мс `--motion-slow`, opacity | все переключения | мгновенная смена |
| Переворот Таро | карты | 450–600 мс на карту (R03 §6.1), существующая колода | bg:tarot | показ без 3D (R03) |
| Появление sheet/шага | UI | 180–240 мс (R03 §6.1) | все | без перемещения (R03) |

Запреты (наследуются из R03 §6.2 + план §7.3): не анимировать `filter: blur`, `background-position` на больших областях, layout-свойства; никакого звука; виджет-фазы луны и карточки агентов — по R03, здесь не дублируются.

### 3.2. Пауза фона — настройка пользователя (план E18)

**Требование W3C Pause-Stop-Hide (2.2.2):** автодвижение > 5 с должно иметь механизм паузы. Reduced motion — системная настройка, не замена кнопки (R03 §6.2).

- Настройка **«Анимация фона»** в Профиле: toggle, default = «вкл».
- Хранение: localStorage `oracle.bgAnimation` (паттерн локальных настроек миниаппа; синхронизация с аккаунтом — вне скоупа A).
- Действие: класс `bg-paused` на `#app-root` → все `animation` слоёв L2–L5 = `none`, статичный кадр, метеоры скрыты. L0/L1/L3 остаются — композиция не «умирает».
- Формулировка: «Анимация фона. Можно выключить, если движение отвлекает или тратит батарею» + подпись, что чтение/функции не зависят от анимации.
- Автопауза: `visibilitychange` → `animation-play-state: paused` — вкладка Telegram WebApp в фоне не тикает.

### 3.3. Reduced motion (план E23; R03 §6.3)

Единый блок в `00-tokens.css`, покрывающий **все** существующие слои:

```css
@media (prefers-reduced-motion: reduce) {
  .starfield::before, .starfield::after, .galaxy, .nebula,
  .lilith-sil, .meteor, .twinkle, .constellations { animation: none !important; }
  .meteor { display: none; }
  #app-root, .sky-layer { transition: none !important; }
}
```

**Гэп текущей базы (исправить при реализации):** сейчас reduced-motion блоки размазаны по модулям (04, 07 — без `!important`; `starDrift`, `gPulse`, `lilBreathe`, `nebulaDrift` не покрыты). Спека требует один authoritative-блок; локальные правила модулей удалить.

## 4. Perf-бюджет (проверка Frontend Engineer)

### 4.1. Обязательства волны A (уровень кода — проверяются ревью)

| Метрика | Порог | Как мерить |
|---|---|---|
| Одновременных CSS-анимаций | ≤ 2 слоя на состояние | DevTools Rendering → Animation |
| CSS-анимации — только `transform`/`opacity` | 100% **новых/изменяемых** keyframes фона | код-ревью |
| Main-thread jank при скролле чата | нет дропов > 3 кадров подряд | профилировка на среднем Android |
| FPS фоновых анимаций | ≥ 55 desktop, ≥ 50 мобильный | DevTools Performance 10-с замер |
| Пауза E18 + visibilitychange | работают | ручная проверка §6 |
| Reduced motion E23 | один блок, все слои | grep + прогон §6 |

### 4.2. Измеренные отклонения существующих ассетов (приняты бордом для волны A, не блокеры)

| # | Факт | Эффект | Судьба |
|---|---|---|---|
| 1 | `lilith-sil.png` 307 KB при 387×800 | ~12% бюджета первого входа mobile (3G ≈ 1,6 c докачки) | отложено: ре-экспорт ≤80 KB в этапе изображений борда (§7) |
| 2 | `bg-cosmos-2.jpg` 1300×1300 на 2560×1440 — апскейл ≈2× | мягкость/мыло на больших мониторах | отложено: wide-кадр в этапе изображений борда (§7) |
| 3 | `filter: blur(60px)` на `.nebula` | дорогой композитинг на мобильных GPU | отложено: pre-blurred текстура в этапе изображений борда; до тех пор слой остаётся как есть |
| 4 | `mix-blend-mode: screen` на `.galaxy` | композитинг-стоимость покадрово | отложено вместе с п.3 |
| 5 | Дубли анимаций `15-ritual-redesign.css` (42 шт.) | вне скоупа фона | помечено для R06/дизайн-ревью: в новые макеты не переносить без perf-сверки |

Правило честности: пункты 1–4 — **не silent-долг**, они заведены в список CEO для этапа изображений борда (BUS-963) и в §7 этого документа.

### 4.3. Прогрессивная загрузка (существующие ассеты)

1. Первая отрисовка: L0 + L2 — 0 KB, мгновенно.
2. L1 — `preload as=image fetchpriority=high` (уже в index.html), кадр по media-query.
3. L3 SVG созвездия — инлайн, ~2 KB.
4. L5 агент — `loading="eager"` только на welcome (текущее поведение), декод async.
5. Метеоры/галактики — активируются после `load` L1.

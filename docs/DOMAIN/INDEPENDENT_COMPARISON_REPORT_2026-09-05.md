## 2. Независимые авторитеты

- **A. NASA/JPL Horizons API** — observer quantity 31 (apparent ecliptic-of-date
  longitude), геоцентр 500@399. Отдельная реализация и пайплайн от Swiss Ephemeris.
- **B. Skyfield 1.55 + JPL DE421.bsp + ERFA (pyerfa)** — полностью независимый путь:
  чебышёвская интерполяция DE421, прецессия-нутация IAU 2006/2000A (`pnm06a`),
  истинный наклон (`obl06`). Ни код, ни данные не пересекаются со Swiss Ephemeris.

Наш движок: OracleAI Engine v2 → Kerykeion 5.12.9 → Swiss Ephemeris 2.10.3.2;
Tropical, Apparent Geocentric, Placidus, true node. Настройки зафиксированы в артефакте.

| berlin_2020_dst | 0,000322° | 0,000311° |

| utc_2000_midnight | 0,000055° | 0,000148° |
| anchorage_2000_high_lat | 0,000282° | 0,000207° |
| sydney_1990_edge_lon | 0,000293° | 0,000325° |
| kazan_1990_date_only | 0,000287° | 0,000313° |
| **Итого (140 сравнений)** | **0,000379° (1,37″)** | **0,000400° (1,44″)** |

Худшее тело во всех случаях — Луна (наиболее быстрое тело; сказывается также
разница версий эфемерид DE421 vs DE431/SE и округление ответа Horizons до 10⁻⁷°).
Согласие двух независимых авторитетов между собой ≤ 0,0004° — взаимное подтверждение.

**Вывод о приемлемой точности.** Максимальное расхождение ≈1,4 угловой секунды
(0,0004°) на 4–5 порядков меньше любых астрологических орбов (6–8° у нашего
контракта `chart_contract`): расхождение не может изменить ни знак/дом/аспект в
практических случаях, ни содержание интерпретаций. Точность считаем **приемлемой**
для всех 7 типов кейсов; расхождение полностью объяснимо (версия эфемерид +
момент снапшота) — аномальных выбросов нет.

## 4. Что остаётся вне сравнения (честная граница)

ASC/MC/дома Placidus, узлы/Лилит, ретро-флаг, Хирон/астероиды — зафиксированы в
`non_comparable` каждого кейса. ASC/MC зависят от конвенции дома/времени, у
авторитетов нет «публичного Placidus»; узлы чувствительны к политике true/mean.
Это остаётся в `ACCURACY_MATRIX.md` как open: *polar houses, node/Lilith external
reference, retrograde-boundary cases*. Date-only кейс сравнивает только планеты
(угловые данные по контракту отсутствуют — `precision_state: date_only`).

## 6. Воспроизводимость

```bash
ORACLEAI_BSP_DIR=<dir с de421.bsp> python scripts/independent_comparison.py \
    --out docs/DOMAIN/independent_comparison_2026-09-05.json
```

Skyfield-часть офлайн-воспроизводима (DE421.bsp + built-in timescale); JPL-часть
требует сети, ответы детерминированы (Horizons quantity 31). Входы = golden-кейсы.
DE421 покрывает 1900–2050 — все кейсы внутри диапазона.

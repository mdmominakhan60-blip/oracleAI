## Status interpretation

`Implemented` means the repository has a deterministic path and local regression coverage. `External comparison open` means the existing direct `pyswisseph` harness shares the Swiss Ephemeris kernel with the canonical adapter and therefore is not an independent vendor oracle. `Open` items are not silently upgraded to green by the existence of code or a fixture.

The release verdict for the full Gauntlet remains **BLOCKED** until the following evidence gaps are closed: broader independent external astrology coverage beyond the captured representative planetary case; explicit Swiss Ephemeris/Kerykeion licensing and distribution decision; polar house/angle behavior policy; broader node/Lilith and retrograde-boundary references; live-model grounding evaluation; and manual PDF/UI cross-surface review.
